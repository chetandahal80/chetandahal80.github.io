01 Planning & Control Active
Human-Aware Trajectory Planning via Model Predictive Control
Designing a wheeled mobile robot that plans dynamically safe paths around moving humans in real time.
Mar 2026 – Present
＋
ROS 2MPCOptimization Motion PlanningHuman-Robot InteractionPython / C++
The Challenge

Most mobile robots plan paths as if humans are static obstacles. In real shared spaces such as warehouses, hospitals, labs, humans move unpredictably. A robot that ignores human motion will either stop constantly or create unsafe close-passes that erode trust.

The goal: build a planner that treats human motion as a first-class input, generating trajectories that are not just collision-free but socially comfortable while maintaining appropriate distances without sacrificing robot efficiency.

My Approach

I formulated the robot's kinematic model (differential drive) as a constrained nonlinear optimization problem solved in a receding-horizon MPC loop. Human positions from a tracker are fed into the MPC cost function and constraints at each timestep.

The cost function penalizes proximity to detected humans, while hard constraints ensure the robot stays within its dynamical limits. This generates smooth, reactive trajectories that adapt in real time. Validation is ongoing in ROS 2 simulation with Gazebo before hardware transfer.

02 UAV / Aerial
Autonomous UAV for Radiation Mapping in GPS-Denied Environments
End-to-end autonomy pipeline for mapping radiation in indoor, GPS-denied spaces using SLAM and ROS.
Aug 2025
＋
ROSPX4 SITLGazebo Hector SLAMRVizGrid Maps
The Challenge

In nuclear facilities or post-disaster environments, humans cannot safely enter radiation-contaminated spaces. A UAV could map these environments, but GPS is unavailable indoors and radiation sensors must be fused with spatial data to produce a meaningful map, not just point readings.

The hard parts: making the UAV localize itself without GPS, avoiding obstacles in cluttered indoor spaces and overlaying sensor data on a 2D grid map in real time.

My Approach

I built the full simulation stack from scratch: PX4 SITL for flight control, interfaced with ROS, running inside a custom Gazebo world representing a cluttered indoor environment.

Hector SLAM provides pose estimation and map building using only a 2D LiDAR with no GPS required. A map-driven obstacle avoidance layer guides the UAV through the space. Radiation readings are projected onto the occupancy grid and visualized as a heatmap in RViz, giving operators a live picture of contamination distribution.

Key sim-to-real challenges I addressed: TF frame consistency across the full stack, sensor noise modeling and coordinate frame alignment between PX4's NED frame and ROS's ENU convention.

03 UAV / Aerial Research
LiDAR-Inertial SLAM on Custom Quadrotor (FAST-LIO)
Real-time onboard 3D mapping and state estimation deployed on a self-built quadrotor using an NVIDIA Jetson Orin Nano.
Jan 2025 – Present
＋
FAST-LIOLiDAR-Inertial SLAMJetson Orin Nano Quadrotor3D MappingROS 2
The Challenge

Running 3D LiDAR-inertial SLAM fully onboard a UAV, without offloading to a ground station, is computationally demanding. The challenge was integrating a tightly-coupled SLAM algorithm (FAST-LIO) with limited onboard compute, on a custom-built quadrotor with real vibration and sensor noise.

Additionally, the UAV itself had to be assembled and tuned to fly stably enough that SLAM could produce clean maps. Hardware and software are tightly coupled here.

My Approach

I assembled the quadrotor from scratch using commercial frames and electronic components, then tuned the flight controller for stable hover. An NVIDIA Jetson Orin Nano was selected as the onboard computer for its GPU-accelerated compute in a power-efficient package.

FAST-LIO, a tightly-coupled LiDAR-inertial odometry algorithm, was integrated and configured for real-time operation on the Jetson. It fuses LiDAR point clouds with IMU data to estimate pose at high frequency, producing a dense 3D map of the environment as the UAV flies. This work directly supports the wildfire fuel moisture estimation research at UNLV's lab.

04 Deep Learning
Deep Learning Pipeline for Hyperspectral NDVI Prediction
A Hybrid 3D-2D U-Net with Transformer encoders that maps high-dimensional hyperspectral imagery to vegetation health indices with R² of 0.9692.
Dec 2025
＋
PyTorchU-NetTransformers Hyperspectral ImagingRegressionDeep Learning
The Challenge

Hyperspectral cameras capture hundreds of spectral bands per pixel, creating 3D input tensors that are far richer and far harder to process than standard RGB images. The task: predict NDVI (Normalized Difference Vegetation Index), a 2D continuous map of vegetation health, from these high-dimensional inputs.

Standard 2D CNNs discard spectral structure. Standard 3D CNNs are too expensive. The model needed to capture both spectral depth and spatial context efficiently.

My Approach

I implemented a Hybrid 3D-2D U-Net: the encoder uses 3D convolutions to extract spectral-spatial features from the hyperspectral patch, which are then decoded through 2D layers to produce the continuous NDVI output map. This achieved RMSE 0.0443 and R² 0.86.

To push further, I integrated Transformer encoders into the CNN bottleneck, combining local feature extraction with global context modelling across the spatial dimensions. This hybrid architecture achieved RMSE 0.0208 and R² 0.9692, a significant jump. Training used global min-max normalization, data augmentation and validation-based checkpointing throughout.

05 Planning & Control
3D Human Tracking: YOLOv8 + Kalman Filter + RGB-D
Multi-target 3D human tracking for mobile robot safety, fusing depth camera detection with a Kalman filter and optimal data association.
Jul 2024
＋
ROS 2YOLOv8Kalman Filter RGB-D CameraData AssociationPython
The Challenge

For a robot to safely navigate around people, it needs more than "there's a person at pixel (x, y)." It needs stable 3D position estimates across multiple people, accounting for sensor noise, occlusions and the fact that people come and go from the scene.

Naive detection-only approaches flicker and lose track identity, making them unreliable for safety-critical use. The challenge was building a tracker that stays stable across time, even under noisy depth readings and partial occlusions.

My Approach

YOLOv8 detects people in the RGB image. For each detection, the corresponding depth value is used to back-project the 2D bounding box center into a 3D position in the robot's coordinate frame.

A multi-target Kalman filter maintains a smoothed estimate of each person's 3D position and velocity over time. The hardest part is the data association problem: when there are multiple detections and multiple tracks, which detection belongs to which track? I applied the Jonker–Volgenant algorithm, an efficient implementation of optimal assignment, to solve this robustly at each timestep, enabling stable identities even in crowded scenes.

06 Embedded / Edge
Embedded ML for Hand-Tool Ergonomics Monitoring
A TinyML classifier running on an STM32 microcontroller that detects unsafe wrist posture during hand-tool use in real time with 94% accuracy on the MCU.
Nov 2025
＋
TinyMLSTM32MEMS IMU Edge AIClassificationMEMS Studio
The Challenge

Repetitive awkward wrist postures during hand-tool use are a leading cause of musculoskeletal disorders in manufacturing workers. Existing solutions require expensive motion-capture setups or clinician observation, neither of which is scalable to a factory floor.

The goal: build a wearable, real-time ergonomic monitor that runs entirely on a cheap microcontroller with no cloud, no latency, no battery-draining wireless streaming.

My Approach

I designed and built an STM32 + MEMS IMU prototype using MEMS Studio to capture wrist and forearm motion during simulated hand-tool tasks. The IMU records acceleration and angular velocity at the wrist.

A TinyML model was trained to classify motion windows as safe vs. unsafe posture, then quantized and deployed directly onto the STM32 microcontroller. The result: real-time on-device inference with no host computer required, at approximately 94% classification accuracy, a proof-of-concept that compact AI can work for workplace safety monitoring.

07 Deep Learning
Neural Network Regression for Gas Turbine NOx Emissions
Data-driven MLP model estimating NOx emissions from continuous sensor streams of a gas turbine, without physical simulation.
Apr 2025
＋
PyTorchMLPRegression Sensor DataDeep Learning
The Challenge

Physical models for gas turbine NOx emissions are complex, computationally expensive, and require detailed thermodynamic parameters. A data-driven approach could predict emissions directly from the sensor streams already present in any modern turbine, making real-time monitoring practical.

The challenge: the relationship between operating conditions and NOx is highly nonlinear, and the model must generalize well, not just fit the training set.

My Approach

I developed a Multi-Layer Perceptron (MLP) regression model in PyTorch, trained on continuous gas-turbine sensor data. Rather than fixing an architecture, I designed and evaluated multiple network depths, widths, and activation functions to model the nonlinear relationship systematically.

Models were compared using MSE, MAE, and R² metrics across a validation set to select a configuration with strong generalization performance. This project demonstrated my ability to apply deep learning rigorously to engineering sensor data, not just image classification benchmarks.

08 Planning & Control
Exponential Stabilization of Nonholonomic Mobile Robots
Implementation and validation of a nonlinear feedback control law achieving global exponential convergence for a differential-drive robot from arbitrary initial conditions.
Nov 2022
＋
Nonlinear ControlRobot Kinematics MATLABStability Analysis
The Challenge

Nonholonomic robots, like differential-drive wheeled robots, cannot move sideways. This nonholonomic constraint means that, by Brockett's theorem, no smooth time-invariant feedback law can asymptotically stabilize them. You need time-varying or discontinuous controllers, which are harder to design and analyze.

The challenge: implement a theoretically rigorous nonlinear controller that provably stabilizes the robot to a desired pose from any starting configuration, and verify this in simulation.

My Approach

I reproduced the nonlinear feedback control law from the paper "Exponential Stabilization of Mobile Robots with Nonholonomic Constraints" and implemented it in MATLAB for a two-wheeled robot model.

The controller was tested from a wide range of arbitrary initial conditions, different positions and headings, to demonstrate global exponential convergence of all robot states to the origin. Time-domain simulations show the state trajectories converging at an exponential rate, verifying the theoretical stability guarantees. This project deepened my understanding of nonlinear control theory, which now underpins my MPC work.
